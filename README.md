# Stok Bengkel

Website sederhana untuk mengelola stok sparepart bengkel motor.

## Fitur
- Login untuk mengakses aplikasi
- Tambah barang
- Update stok
- Hapus barang
- Penyimpanan data menggunakan localStorage

## Login
- Username: `admin`
- Password: `admin123`
- Status login berlaku selama tab browser masih terbuka.

> Login ini berjalan sepenuhnya di browser dan hanya cocok untuk penggunaan lokal/demo. Kredensial dapat dilihat dari kode sumber, sehingga tidak memberikan keamanan untuk aplikasi yang dipublikasikan. Gunakan autentikasi backend untuk melindungi data sungguhan.

## Tujuan
Membantu mencatat dan memantau stok barang di bengkel agar lebih rapi dan efisien.

- CSS
- JavaScript
